# 笔记本应用 —— 产品路线图

> 定位：跨平台桌面端笔记应用，Markdown + 实时预览，纯本地存储。
> 场景覆盖：快速随手记 / 知识整理与资料库 / 任务待办 / 代码技术笔记。
> 质量约定：遵循 AGENTS.md —— 每次改动生成 Git commit；每个功能落地时同步编写/更新测试，全部通过后方可交付。

---

## 版本总览

| 版本 | 主题 | 一句话目标 |
|---|---|---|
| **P0（MVP）** | 核心闭环 | 记录 → 自动保存 → 全文找回 |
| **P1** | 效率增强 | 分类/待办/附件增强 + 全局速记与快搜悬浮窗 |
| 暂不做 | 远期内核 | 账号同步、双链、富文本、协作 |

技术底座（Tauri / Electron）待确认，不影响本功能范围，只影响实现层选型。

---

## P0 —— MVP（记录 → 保存 → 找回）

| 功能 | 说明 | 服务场景 |
|---|---|---|
| 笔记列表 + 新建/删除/重命名 | 两栏或三栏布局，侧边为笔记列表 | 全部 |
| Markdown 编辑器 + 实时预览 | 分屏实时预览，可切换纯编辑视图 | 知识库 / 代码笔记 |
| 自动保存 | 输入即落盘（去抖），界面显示“已保存”状态 | 快速随手记 |
| 全文搜索（主窗口内） | 同时搜标题与正文，即时出结果 | 找回笔记 |
| 文件夹（笔记本）分类 | 一级目录组织，MVP 不引入嵌套 | 知识整理 |
| 代码块语法高亮 | 预览端高亮常见语言 | 代码笔记 |
| 待办勾选 `- [ ] task` | 编辑与预览中可勾选，显示完成度 | 任务清单 |
| 纯本地文件存储 | 每条笔记一个 `.md` 文件，存应用数据目录，天然可备份 | 本地存储 |

### P0 数据与架构预留（为 P1 悬浮窗等留出空间）

- **笔记 = 独立 `.md` 文件** + 轻量索引（标题、所属文件夹、更新时间、笔记 ID）。
- 索引/元数据预留 **frontmatter** 承载空间（标签、置顶、pin 等 P1 字段不再改存储结构）。
- **数据层与 UI 解耦**：核心逻辑（笔记读写、索引、搜索）与窗口 UI 分离，便于 P1 平滑增加第二个窗口（悬浮窗）。
- **快捷键注册机制预留**：MVP 至少提供应用内快捷键注册表；P1 只需在此之上追加系统级全局热键与自定义映射，无需重构。
- **托盘/后台驻留预留**：P0 可最小化到托盘或退出清理，P1 悬浮窗依赖“关窗后仍可响应全局热键”的后台驻留能力。

### P0 验收要点

- 新建→书写→自动保存→重启后内容仍在；删除与重命名正确更新索引。
- 标题/正文关键词可被全文搜索命中并跳转。
- Markdown 渲染与代码高亮、待办勾选状态一致。

## P1 —— 效率增强（首版发布后的后续计划）

### 基础增强

- 标签系统与多级目录；笔记列表内**置顶/固定**。
- 回收站与笔记历史版本。
- 全局“待办聚合视图”：汇总所有未完成任务到一屏。
- 图片/附件：粘贴与拖拽入库。
- 命令面板（`Ctrl+K`）+ 可自定义快捷键设置页。
- 主题（浅色/深色）、字数统计、导出 HTML / PDF。

### P1 重点：全局速记 + 快搜悬浮窗

定位：**“像便签一样随时唤出的小窗口”**，作为快速随手记与快速找回的统一入口，可在任意应用之上呼出。

**呼出与形态**

- 全局快捷键唤出/隐藏（默认方案待定，如 `Ctrl+Shift+Space`），快捷键**可在设置中自行更改**并持久化。
- 小尺寸、无边框窗口；**可拖拽**、记住上次位置；**可置顶**（always-on-top，可开关）。
- `Esc` 隐藏；后台驻留（托盘），关窗不退出，保证热键随时可用。

**功能**

- **速记**：输入文本即写即存 —— 保存为一条新笔记（默认落入“收件箱/速记”文件夹），回车或“保存”按钮落盘并可顺手隐藏窗口；输入可一键清空。
- **快搜**：输入即搜（标题 + 正文），结果列表支持键盘上下选择，回车在主窗口打开并定位该笔记。
- **删除**：在搜索结果上提供删除入口（带确认），删除后索引即时更新。
- 保存与删除在**悬浮窗与主窗口均有入口**，行为一致。

**与主窗口联动**

- 悬浮窗新建的笔记立即出现在主窗口列表中；主窗口打开悬浮窗定位的笔记。
- 索引/搜索复用同一数据层，不复制逻辑。

**验收要点**

- 修改热键 → 重启后仍生效；热键冲突有提示。
- 任意前台应用下可呼出、拖拽、置顶。
- 速记保存、快搜定位、删除三者的数据与主窗口实时一致。

## 暂不规划（避免范围膨胀）

账号体系与云同步、多端协作、双链/知识图谱、富文本（所见即所得）、多人实时编辑、移动端。以上待核心闭环与 P1 验证后再评估。
