# NoteApp v0.1.0 发布说明

> **本版本不含“快速便签 / 悬浮窗”**（全局速记窗、系统级全局热键、托盘常驻均未实现，属 P1 规划，见 `docs/ROADMAP.md`）。
> 本版本聚焦“记录 → 自动保存 → 找回”的完整闭环，以及文件夹 / 回收站 / 拖拽 / 设置 / 侧边吸附等桌面体验。

---

## 亮点

- **纯本地 Markdown 笔记**：一条笔记 = 一个 `.md` 文件（frontmatter 内含标题/文件夹/时间/回收站标记），可直接用任何编辑器打开，天然可备份。
- **桌面软件（Tauri 2 + Svelte + TypeScript）**：安装包小、常驻内存低，复用系统 WebView2。
- **三栏 + 面板级联**：默认仅侧栏（图3）→ 点文件夹滑出笔记列（图4）→ 点笔记滑出编辑区（图5）；再点同类或栏间手柄逐级收回；**窗口宽度随面板开合自动缩放**。
- **编辑体验**：Markdown 实时预览（markdown-it + GFM）、代码块语法高亮、编辑/分屏/预览三视图、`Ctrl+S` 立即保存。
- **自动保存**：输入去抖落盘（默认 600ms，可在设置中调 200–2000ms），状态显示 未保存 / 保存中 / 已保存。
- **全文搜索**：标题 + 正文即时命中、片段高亮、点击跳转（`Ctrl+K` 聚焦）；“全部笔记”视图同时命中回收站条目（🗑️ 标记）。
- **文件夹（一级）**：新建 / 双击重命名 / 悬停 ✕ 删除 / 拖拽排序 / 右键菜单；笔记可拖到文件夹移动。
- **回收站**：删除=软删除（保留结构与元数据），支持单条或整组还原、彻底删除、清空回收站。
- **多选批量**：选择模式 / Ctrl / Shift / 全选 → 批量移入回收站、还原、彻底删除（带确认）。
- **笔记手动排序**：列表内拖拽排序并持久化；可一键“恢复时间序”。
- **待办**：`- [ ]` 在预览中可勾选，源文即时回写 `- [x]`。
- **QQ 式侧边吸附**：图3 状态下拖到屏幕左/右边界越界即贴边、垂直居中并置顶；鼠标离开窗口 3 秒平滑缩进屏幕外；光标靠近屏幕边缘热区滑回。
- **独立设置窗口**（`Ctrl + ,`）：通用（启动布局 / 记住面板）、快捷键（改键 + 冲突提示 + 恢复默认）、存储（路径展示 / 打开目录 / **更改位置并迁移**）、编辑器（默认视图 / 自动保存去抖 / 拼写检查）、窗口与吸附（吸附开关 / 吸附侧 / 缩进延迟 / 置顶 / 热区宽度 / 仅侧栏生效）、关于。
- **存储位置迁移**：使用系统原生“选择文件夹”对话框；复制现有笔记与 `meta.json` 到新目录并切换指针，**原目录保留作备份**，失败不改动配置。

## 安装与运行

| 方式 | 步骤 |
|---|---|
| 免安装 | 下载 `NoteApp.exe` 直接双击运行（无需管理员） |
| 安装包 | 若 Release 附带 `NoteApp_0.1.0_x64_en-US.msi` 或 `NoteApp_0.1.0_x64-setup.exe`，双击安装后从开始菜单启动 |

**环境要求**：Windows 10/11 x64；WebView2 Runtime（Win10/11 通常已内置，缺失时微软官网可单独安装）。

## 数据位置（两个目录，别混淆）

- **笔记目录**（可在 设置 → 存储 中更改/迁移）：默认 `%APPDATA%\com.noteapp.desktop\notes\`，里面是 `<id>.md` 与 `meta.json`。
  **备份只需备份这个目录。**
- **应用数据目录**（系统固定，不可改）：`%APPDATA%\com.noteapp.desktop\`，含 `settings.json`（偏好）、`storage.json`（存储指针）、默认 `notes\`。
  删除它不会删除你的笔记文件（若已迁移），但会丢掉设置与指针，应用会回落到默认目录。

## 使用小抄

- `Ctrl + K` 聚焦搜索 · `Ctrl + ,` 打开设置 · `Alt + N` 新建笔记 · `Ctrl + S` 立即保存 · `Shift + ?` 快捷键帮助
- 快捷键均可在 设置 → 快捷键 中修改（会检测冲突）
- 删除的笔记先进回收站；「清空回收站」才会物理删除

## 已知限制（后续版本计划）

- **无快速便签 / 悬浮窗、无系统级全局热键、无托盘常驻**（P1）
- 屏幕边缘“自动隐藏”目前是应用内的吸附 + 缩进（与 Windows 自带的左右半屏贴靠并存），尚未完全接管系统贴靠行为
- 尚未实现：深色主题、标签、置顶、多级目录、待办聚合视图、附件粘贴/拖拽、命令面板、导出 HTML/PDF、回收站自动清理、笔记历史版本
- 设置中的“记住面板开合”默认关闭（每次启动回到仅侧栏）
