## 1. NoteApp 是什么

一句话：**一个纯本地的 Markdown 笔记软件**，界面是「文件夹 → 笔记列表 → 编辑区」三栏。

三个特点：

- **笔记就是文件**。写一条笔记，磁盘上就多一个 `.md` 文件，用记事本、VS Code 都能打开。软件坏了、卸载了，笔记还在。
- **不用点保存**。你打字，它自己存（默认停手 0.6 秒后写入），右上角会告诉你存没存。
- **不联网、不要账号**。所有内容都在你自己电脑上。

它**不做**的事（当前版本）：不云同步、不手机端、没有多级文件夹、没有图片附件、没有浮窗速记。

## 2. 装好并打开

**免安装版**：把 `NoteApp.exe` 放到一个不会随手删掉的目录（如 `D:\Apps\NoteApp\`），双击即可。不需要管理员权限。

**安装包版**：若拿到 `NoteApp_0.1.0_x64-setup.exe`（NSIS）或 `.msi`，双击安装后从开始菜单启动。

> 要求 Windows 10/11 64 位；软件复用系统的 WebView2 组件，一般已内置。

**第一次打开会看到一个很窄的竖窗口，只有左侧栏**——这是故意的，不是显示错误。

侧栏从上到下：

| 位置 | 内容 |
|---|---|
| 顶部 | 品牌区（NoteApp）+「＋ 新建笔记」按钮 |
| 笔记 | 「🗂️ 全部笔记」（数字是笔记总数） |
| 文件夹 | 「📁 收件箱」等，右侧 ＋ 号可新建文件夹 |
| 其它 | 「☑️ 待办」（未完成数）、「🗑️ 回收站」 |
| 底部 | 「⚙️ 设置」、「⌨️ 快捷键」，以及一行存储位置说明 |

## 3. 前 5 分钟：写下第一条笔记

跟着做：

1. 点侧栏蓝色的 **「＋ 新建笔记」**。窗口变宽，中间滑出**笔记列表**，右边滑出**编辑区**。
2. 点最上方灰字「无标题笔记…」的位置，**输入标题**，比如「我的第一条笔记」。
3. 在下面大块区域**输入正文**，可以试试：

```markdown
# 今天学到的

- 第一件事
- 第二件事

- [ ] 明天要做的事
```

4. 看右上角：打字时是 **「未保存」** → 停手变 **「保存中…」** → 然后 **「已保存」**。**不需要按任何保存键。**

## 4. 界面长什么样：三栏与「逐级滑出」

窗口宽度会**跟着你要看的内容变**，这是它最特别的地方。三个状态：

**状态一 · 只有侧栏（默认）**
窗口很窄，只有左边一列。适合「我就想快速点开某个文件夹」。

**状态二 · 侧栏 + 笔记列表**
**点一下任意文件夹**（比如「收件箱」），中间滑出笔记列表，窗口同时变宽。

**状态三 · 三栏全开**
**点一下列表里的某条笔记**，右边再滑出编辑区。这是完整的写作状态。

**怎么收回**：

- **再点一次**当前所在的文件夹 / 当前打开的笔记，逐级收回；
- 或点两栏之间那条**灰色竖条**（鼠标移上去会变色，上面有 ◀ / ▶ 小箭头）——它就是展开/收回开关。手柄可以单独点，比如只收编辑区、保留列表。

## 5. 写笔记：先用工具栏，再看三种视图

### 5.1 加格式不用背语法：点按钮就行

Markdown 的格式原本是靠「打符号」实现的——加粗要在文字两边各打两个星号 `**`。**你不需要记这些符号**：编辑区上方有一排格式按钮，点一下就好。

**怎么用：**

1. **先选中要改的文字**（鼠标拖选，或双击选一个词）；
2. **点按钮**。比如选中「会议纪要」再点 **B**，预览里它立刻变成加粗。

**没选文字就点按钮**：软件会插入一个空模板，你把内容填进去。比如点「</>」会插入一对代码围栏、光标停在中间；点「▦」会插入一张空表格。

**点错了想取消**：**再点一次同一个按钮**就恢复（粗体再点 B → 回到普通文字）。

**按钮都是什么：**

| 分组 | 按钮 | 作用 |
|---|---|---|
| 文字 | **B** | 加粗 |
| | *I* | 斜体 |
| | S | 删除线（划掉文字） |
| | 高亮 | 给文字加一层颜色底，像荧光笔 |
| 标题 | H1 / H2 / H3 | 一级 / 二级 / 三级标题 |
| 列表与块 | • | 无序列表（圆点） |
| | 1. | 有序列表（会自动编号 1. 2. 3.） |
| | ☑ | 待办任务（前面带可勾选的方框） |
| | ❝ | 引用 |
| | </> | 代码块 |
| 插入 | 🔗 | 链接 |
| | ▦ | 表格 |
| 编辑 | ↶ / ↷ | 撤销 / 重做 |
| **⋯ 更多** | | 点开里面还有「行内代码」和「分隔线」 |

**快捷键**：`Ctrl + B` 加粗、`Ctrl + I` 斜体；撤销 `Ctrl + Z`、重做 `Ctrl + Y`。

> 工具栏只是替你打符号，文件里存的仍是标准 Markdown。
> 这些按钮在**「预览」视图下会隐藏**（预览是只读的），切回「编辑」或「分屏」就会重新出现。

### 5.2 三种视图：编辑、分屏、预览

编辑区右上角三个按钮：**「编辑」「分屏」「预览」**。

- **编辑**：只看输入框，适合专心打字。
- **分屏**：左输入、右实时预览——**默认就是这个**（可在设置里改）。
- **预览**：只看排版效果。

Markdown 还支持标题 `#`、引用 `>`、表格、链接自动识别。代码块自动上色，支持 js/ts/python/bash/rust/go/java/c/cpp/css/sql/json/markdown/xml/yaml 等。

## 6. 保存：不用点保存按钮

- 打字后**停手一小会儿**（默认 600 毫秒）自动写入。
- 右上角状态：**未保存 → 保存中… → 已保存**。
- 想立刻存：按 `Ctrl + S`。
- 觉得 600 毫秒太急/太慢：**设置 → 编辑器 → 自动保存去抖**（200–2000 毫秒）。
- 关窗口也不会丢：关闭前会把没写完的内容刷进文件。

## 7. 整理笔记：文件夹

文件夹只有**一级**（没有子文件夹）。

| 想做什么 | 怎么做 |
|---|---|
| 新建文件夹 | 侧栏「文件夹」右侧的 **＋**，或**在侧栏空白处点右键** → 「新建文件夹」 |
| 在某个文件夹里新建笔记 | **右键该文件夹** → 「在「××」中新建笔记」 |
| 改名字 | **双击**文件夹名，直接改，回车确认 |
| 删除文件夹 | **右键** → 「删除（移入回收站）」，或在文件夹名上悬停后点出现的 **✕** |
| 调整文件夹顺序 | **按住文件夹名上下拖**，出现插入线后松手 |
| 把笔记挪到别的文件夹 | 用编辑区左上角的**文件夹下拉框**；或把笔记**拖到侧栏的文件夹上** |

> 删文件夹不会真删：它和里面的笔记一起进**回收站**，可整组还原。

## 8. 整理笔记：标签

标签是**跨文件夹**的分类方式。一条笔记可以属于「工作」文件夹，同时带 `#会议` `#重要`。

**加标签**：

1. 打开一条笔记；
2. 找到标题下面 **「标签」** 那一行；
3. 在右边输入框打字，**按回车**即成为一个标签；
4. 想一次加多个：用**空格或逗号**分隔，例如输入 `会议 重要` 再回车。

**按标签找笔记**：有标签后，笔记列表上方会出现标签按钮，如 `#会议 1` `#重要 1`（数字是使用它的笔记数）。

- 点一个标签 → 列表只剩带该标签的笔记，列表标题变成 `#会议`；
- 点 **「清除标签」** → 退出筛选。

**删标签**：把鼠标移到「标签」行里某个标签上，点右边的 **✕**。

> 标签按钮统计的是**整个笔记库**的标签，所以即使在单篇文件夹里，也能看到并切换到别的标签。

## 9. 把重要的钉在最上面：置顶

**置顶的笔记永远排在列表最前面**，不管它多久以前写的。三种方式：

1. 打开笔记 → 编辑区右上角 **「📌 置顶」**（置顶后变成「📌 已置顶」）；
2. **右键笔记行** → 「置顶」；
3. 批量：进「选择」模式选中多条 → 操作条点 **「置顶」**。

置顶后列表里会带 📌 标记，列表标题旁显示「· N 条置顶」。

**注意**：置顶笔记**不能**被拖进普通区域。这是故意的——否则「置顶」和「手动排序」两套顺序会互相打架。想让它回普通区，先取消置顶。

## 10. 待办清单：把所有没做完的事汇到一屏

**在笔记里写任务**（Markdown 复选框语法）：

```markdown
- [ ] 整理上周会议纪要
- [x] 发会议邀请
```

预览里它们会变成**可点的方框**，点一下就改掉源文件里的 `- [ ]` → `- [x]`。

**在一个地方看全部未完成**：点侧栏 **「☑️ 待办」**（数字是未完成总数），中间列出整个库所有没做完的任务，每条都标着来自哪篇笔记、哪个文件夹、**第几行**。

- **勾选方框** → 任务完成，**立刻从未完成清单消失**（源文件同步改成 `- [x]`）；
- **点任务文字** → 跳回那篇笔记，编辑区滚动到该行并**短暂高亮**；
- **「显示已完成」** → 把做完的也列出来（带删除线）；再点变回「隐藏已完成」；
- **搜索框**在这个视图里也能用：按任务内容、笔记标题或文件夹过滤。

> 已完成任务默认不显示，因为待办视图的用途就是回答「还剩什么没做」。

## 11. 找回笔记：搜索

中间栏顶部有搜索框（或按 `Ctrl + K` 直接聚焦）。

- 输入关键词，**标题和正文一起搜**，结果实时出现；
- 命中处**高亮**成黄色底，并标注「标题命中」或「正文命中」；
- 点结果跳转；
- 在「全部笔记」视图搜索时，**回收站里的笔记也会被搜到**（带 🗑️ 标记），点它会进入回收站查看。

> 标签不参与搜索（只搜标题与正文）。按标签找，用第 8 节的标签按钮。

---

## 12. 删错了不怕：回收站

NoteApp 的「删除」是**软删除**。

- 删除笔记/文件夹 → 进**回收站**，文件还在磁盘上，只是打了「已删除」标记；
- 在回收站里打开的笔记是**只读**的，顶部有黄色提示条，上面直接有「还原」和「彻底删除」按钮；
- 点侧栏 **「🗑️ 回收站」** 看全部已删除内容；删除的文件夹单独列在「已删除文件夹」区域，能**整组还原**；
- 想真删：右键条目「彻底删除」，或点右上角 **「清空回收站」**（二次确认，**不可恢复**）。

## 13. 一次处理多条：多选与批量操作

1. 点列表右上角 **「选择」** 进入选择模式；
2. 勾选多条（或点「全选」；也可按住 `Ctrl` / `Shift` 点）；
3. 上方出现批量按钮：**移入回收站** / **还原** / **彻底删除**（回收站视图）/ **置顶** / **取消置顶**。

点「取消」退出选择模式。

## 14. 换外观：浅色 / 深色 / 跟随系统

按 `Ctrl + ,` 打开设置，**「通用」**页第一行就是**主题**：

- **浅色**（默认）
- **深色**
- **跟随系统**：跟着 Windows 的浅色/深色设置走。你在 Windows 里切主题，NoteApp **立刻跟着变**，不用重开。

选择会立即生效，并同时应用到**主窗口和设置窗口**，重启后保持。

## 15. 设置窗口里还有什么

设置是**独立窗口**，左边六个分类：

| 分类 | 能改什么 |
|---|---|
| **⚙️ 通用** | 主题、启动布局（打开时停在哪一栏）、记住面板开合 |
| **⌨️ 快捷键** | 给「新建笔记 / 聚焦搜索 / 立即保存 / 打开设置 / 快捷键帮助」改键；冲突会提示；可单项或全部恢复默认 |
| **💾 存储** | 看当前笔记目录 / 应用数据目录 / 设置文件位置；每行有「打开」按钮；**更改存储位置并迁移**（整体搬到新目录，原目录保留作备份） |
| **📝 编辑器** | 默认视图、自动保存去抖、拼写检查 |
| **📌 窗口与吸附** | 侧边吸附开关、吸附侧、缩进延迟、缩进后置顶、唤出热区宽度、是否只在「仅侧栏」态生效 |
| **ℹ️ 关于** | 版本号、数据位置 |

**改键怎么用**：点某一项右边的键位按钮 → 出现「按下组合…」→ 按新组合键。`Esc` 取消，`Backspace` 清除该快捷键。要求至少带 `Ctrl` / `Alt` / `Meta` 之一。想还原就点那行的 **「默认」**。

## 16. 快捷键速查

随时按 `Shift + ?` 调出这张表（也可点侧栏「⌨️ 快捷键」）：

| 快捷键 | 作用 |
|---|---|
| `Alt + N` | 新建笔记 |
| `Ctrl + K` | 聚焦搜索框 |
| `Ctrl + S` | 立即保存 |
| `Ctrl + ,` | 打开设置 |
| `Shift + ?` | 打开快捷键帮助 |
| `Esc` | 关闭弹层 / 取消捕获 |

以上都能在 **设置 → 快捷键** 里改。

**鼠标操作**：

| 操作 | 结果 |
|---|---|
| 点文件夹 | 滑出笔记列表；再点收回 |
| 点笔记 | 滑出编辑区；再点收回 |
| 双击文件夹名 | 重命名 |
| 右键文件夹 / 笔记行 / 空白处 | 打开上下文菜单 |
| 拖文件夹 | 调整顺序 |
| 拖笔记 | 拖到文件夹=移动；拖到回收站=删除；列表内拖=手动排序 |
| 悬停文件夹后的 ✕ | 快捷删除该文件夹 |

## 17. 常见问题

**Q：窗口怎么这么窄？是不是坏了？**
不是。默认停在「仅侧栏」（第 4 节）。点一下文件夹或栏间灰色手柄就会变宽。

**Q：我明明保存了，为什么「已保存」不见了？**
右上角显示的是**当前这篇**的状态；切换笔记后会重置为「已保存」。

**Q：列表顺序怎么怪怪的？**
**置顶的永远在最前**，其余默认按更新时间倒序。若你手动拖过笔记，就变成「手动排序」，列表标题会显示出来，旁边有 **「恢复时间序」** 按钮可一键切回。

**Q：为什么置顶的笔记拖不动？**
有意设计（第 9 节）。先取消置顶再拖。

**Q：删掉的笔记去哪了？**
回收站，文件还在。彻底删除或清空回收站才是真删（第 12 节）。

**Q：能换笔记存放位置吗？**
能。设置 → 存储 → 「更改存储位置（迁移）」。建议选**空目录**；迁移会复制笔记和元数据并切换指针，**原目录内容保留**。

**Q：会自动清理回收站吗？**
当前版本不会，一直留着直到你手动彻底删除。

**Q：能贴图片吗？**
当前版本不支持图片附件，只能写引用外部图片链接的 Markdown。

**Q：能同步到别的电脑吗？**
没有内置同步。但笔记就是普通文件，可以用网盘同步那个**笔记目录**，或用「存储 → 迁移」手动搬。

**Q：误删了应用设置会怎样？**
设置目录里是偏好设置和「笔记目录在哪」的指针。删掉**不会删笔记**，但软件会回到默认目录、表现为「笔记不见了」。所以**备份只需备份笔记目录**。

## 18. 我的笔记存在哪里

最值得记住的一节。涉及**两个目录**，别混淆：

| | 笔记目录（**要备份的是这个**） | 应用数据目录 |
|---|---|---|
| 默认位置 | `%APPDATA%\com.noteapp.desktop\notes\`（可改） | `%APPDATA%\com.noteapp.desktop\`（不可改） |
| 里面有什么 | 一条笔记一个 `.md` + `meta.json`（文件夹顺序、回收站登记等） | `settings.json`（偏好）、`storage.json`（指向笔记目录的指针） |
| 删掉的后果 | **笔记全丢** | 只丢设置和指针：笔记文件还在，但软件回落看默认目录，表现为「笔记不见了」 |

**快速打开**：设置 → 存储，每一行右边都有 **「打开」** 按钮。

**备份**：复制**笔记目录**到网盘 / U 盘 / 另一块硬盘即可。笔记是纯文本。

**用别的编辑器看看**：随便挑一个 `.md` 用记事本打开，开头长这样：

```text
---
id: n-mu6zhwacci6xha
folder: 工作
title: 会议纪要
tags: ["会议","重要"]
pinned: true
createdAt: 2026-09-18T13:18:18.804Z
updatedAt: 2026-09-18T13:18:27.300Z
---

## 本周待办
- [ ] 整理上周会议纪要
```

`---` 之间那段叫 **frontmatter**，记录「标题 / 文件夹 / 标签 / 是否置顶 / 时间」；下面是正文。**这段别手改乱**，否则软件可能读错；改正文随便改。

---
