## 新增功能

### 1. 主题：浅色 / 深色 / 跟随系统
- 三档主题，**主窗口与设置窗口同时生效**、重启保持；
- 「跟随系统」在系统主题变化时**实时跟随**（不是只在启动时读一次），切走后自动释放监听；
- 全部配色走 CSS 变量（有样式契约测试：除变量定义与代码高亮外不允许硬编码颜色）；
- 两个窗口的 HTML 都带**首屏主题引导脚本**，深色用户不会看到白屏闪烁。

### 2. 标签与置顶
- 编辑区回车即加标签（空格 / 逗号可一次多个），点标签条按标签筛选，再点取消；
- 笔记可置顶并固定排在列表最前（与手动排序、时间序**并存**，置顶区内仍可手排）；
- 两者都写进 `.md` 的 frontmatter（`tags` / `pinned`），**文件自解释**，换机器/换编辑器都不丢。

### 3. 待办聚合视图
- 侧栏「☑️ 待办」把**全库**未完成的 `- [ ]` 汇总成一屏，显示来源笔记与文件夹；
- **勾选即回写源文**（`- [x]`），从未完成清单消失；
- 点任务**跳回原笔记并定位该行**（短暂高亮）；可切换「显示已完成」。

### 4. Markdown 格式工具栏（不必再背语法）
- 加粗 / 斜体 / 删除线 / 高亮、三级标题、无序·有序·待办·引用·代码块、链接 / 表格、撤销 / 重做
  （`⋯` 里还有行内代码与分隔线）；
- 选中文字点按钮即套上语法、**再点一次取消**；没选文字则插入空模板并把光标放到该填的位置；
- 新增 `==文字==` → `<mark>` 高亮渲染（可嵌套其它行内语法，未闭合时按普通文本处理，不吞后续内容）。

### 5. 《使用教程》
- 零基础上手文档（`使用教程.md`）：每一步都写明「点哪里 → 会发生什么」；
- 附一份**可导入的教程笔记**（`docs/import/`）。

### 6. 布局宽度与分屏比例
- 修掉「仅预览 / 仅编辑只占半宽」；
- 修掉「窗口放大后右侧留白」；
- 分屏中间的分隔条**可拖动改比例**（20%–80%，写进 `settings.json` 并重启保持），**双击恢复各半**。

## 可靠性与工程改进（本版另一条主线）

v0.1.0 之后花了大量精力在「让它稳定地双击就能开」上，成果都在本版：

- **启动器与桌面快捷方式**：`launch-noteapp.bat` 与 `npm run shortcut:desktop`
  创建的桌面图标走 `cmd /c start`，**绕开 Windows 的「无法验证发布者」提示**；
- **自签名代码签名证书**（`npm run sign:exe`）：证书装进**本账户**的受信任根与受信任发布者，
  签名后弹窗从「未知发布者」变为显示 `NoteApp Local Build`；已接入构建后步骤，每次编译自动签名；
- **构建前自动收尾**：结束正在运行的应用（避免 exe 被占用导致 `os error 5`）+ **清空 WebView2
  profile 内容**（修掉「编译一次就把应用搞坏」的根因；目录/链接本体保留）；
- **构建后去除网络标记**（等价右键「解除锁定」），减少不必要的安全提示；
- **启动日志与 panic 记录**：release 是 GUI 子系统、stderr 会被系统丢弃，现在启动上下文与
  panic 回溯都落盘到 exe 同目录的 `noteapp-log.txt` —— 「窗口闪一下就消失」这类问题从此有据可查；
- **诊断与取证工具**：`npm run diagnose:startup`（启动诊断 + WebView2 崩溃查询）、
  `npm run probe:ui`（对「窗口空白」直接取证：页面状态、已加载资源、JS 异常、可截图）、
  `npm run link:webview`、`npm run clean:360`；
- **规范门禁 `npm run verify`**：单测 + 类型检查 + Prettier（`--check`）+ `cargo fmt --check`
  + `cargo clippy -D warnings`，CI 执行同样五项；配套 `.editorconfig`、编码守卫、行尾守卫、
  测试命名守卫；
- **修掉一个真实前端缺陷**：`App.svelte` 里 `core` 未声明为 `$state` 却被模板引用
  （Svelte 5 明确告警「不会触发响应式」，此前靠其它状态变化"顺带"刷新才显示正确）；
  同时修掉 20 处 `<label>` 语义误用（Svelte 编译警告 26 → 5，视觉零变化）；
- **删除 P0 时期的浏览器原型 `demo/`**（含 4 个专属测试），仓库只保留一条生产实现线。

## 安装与运行

| 方式 | 步骤 |
| --- | --- |
| 免安装（推荐） | 解压/下载后双击 `noteapp.exe`（无需管理员权限，不写注册表） |
| 桌面图标 | 仓库内跑 `npm run shortcut:desktop`，桌面出现 `NoteApp` 图标（**不会弹发布者提示**） |
| 安装包 | 若 Release 附带 `NoteApp_0.2.0_x64_en-US.msi` 或 `NoteApp_0.2.0_x64-setup.exe`，双击安装后从开始菜单启动 |

**环境要求**：Windows 10 / 11 x64；复用系统 **WebView2**（Win10/11 通常已内置）。

> **看到「无法验证发布者 / 你想运行此文件吗」？** 这是 Windows 对未签名或**新编译**程序的例行提示，
> 与软件行为无关。发行商显示 `NoteApp Local Build` 说明它已被本机自签名证书签名；
> 想彻底不弹就用桌面图标启动。详见 `docs/PROGRESS.md` §1.16。

## 升级说明（从 v0.1.0 升上来）

**直接替换 `noteapp.exe` 即可，笔记与设置都不用动** —— 数据不在 exe 里：

- **笔记目录**：默认 `%APPDATA%\com.noteapp.desktop\notes\`（可在 设置 → 存储 中更改/迁移）。
  **备份只需备份这个目录。**
- **应用数据目录**：`%APPDATA%\com.noteapp.desktop\`，含 `settings.json`（偏好）、
  `storage.json`（存储指针）、默认 `notes\`。

## 已知问题

1. **本机专属**（与代码无关）：某些安全软件的**残留过滤驱动**会按路径拦截本应用写
   `%LOCALAPPDATA%\com.noteapp.desktop`，导致启动时 `Failed to setup app: 拒绝访问`、窗口闪退。
   本机已用「profile 目录重定向」绕开（`npm run link:webview`），**该目录链接不要删除**。
   详见 `docs/PROGRESS.md` §1.16。
2. **5 条 Svelte a11y 编译警告**：主窗口里 `<div>`/`<span>` 绑定 click/contextmenu 但缺 ARIA role
   与键盘处理，属待办（不影响功能）。
