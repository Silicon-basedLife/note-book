⌨️ 快捷键

Ctrl + K聚焦搜索（范围含回收站）

Esc关闭弹层 / 退出重命名

鼠标操作

  • 点击文件夹：展开/收起该文件夹的笔记列表
  • 双击文件夹名：重命名；悬停右侧数字变 ✕ 可删除
  • 右键文件夹 / 笔记 / 空白 / 回收站：上下文菜单
  • 拖拽：拖笔记到文件夹 = 移动/还原；拖文件夹 = 调序；列表内拖 = 排序
  • 选择：展开列表顶部“选择”进入多选，或 Ctrl+点击 多选后批量移入回收站

说明：浏览器演示无法使用真实“全局”快捷键与系统级窗口拖拽；桌面版（P1）将支持全局速记窗与可自定义热键。
